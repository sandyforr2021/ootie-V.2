## 指定 NET 公開試穿撤回

使用者明確選擇「先取消公開，等確認授權後再分享」。目標為「毛絨娃娃印花大學T」的單一分享 `4d02eaaa-5ca5-45ce-9c3c-96ec9485039c`。

Render 既有服務的建置完成後執行有範圍限制的維護動作：比對專案、服務、作者、分享及商品網址，透過 Storage API 刪除公開圖片副本，再刪除公開分享列；保留原工作與私人 `result_path`。完成記號保存在該工作 `result_data`，後續部署不會再次撤回，因此不妨礙使用者確認授權後重新發布。不讀取或輸出服務金鑰。

- 沒有單品標記或已不公開的收藏貼文，不會把整張人物照當商品圖套用。
- 回報「需討論」中的統計定義、穿著次數規則、SOS 合併社群、投票、贈衣等產品重設，沒有擅自改成新的商業規則。
