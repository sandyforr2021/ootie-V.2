## 實測與限制

- 全套 npm test：358 前端測試、19 隔離／媒體測試、81 Gateway 測試、4 readiness 測試通過；schema 靜態檢查通過。
- 正式版建置通過。免費主機隔離壓測：48 次圖片請求、48 次健康檢查、8 次圖像處理，峰值 RSS 157 MiB，失敗 0、外部 AI 呼叫 0。
- 真實三件試穿使用既有團隊 AI 模特兒，非真人效果準確度的證據；逐次生成可能改變前一步細節。共扣 6 贈點，未提高額度上限或加入付費方案。
- 去背只處理可可靠判斷的單色背景；複雜背景保留原圖，不宣稱有完整人像／衣物分割能力。
- 衣物辨識透過使用者按鈕啟動，在瀏覽器 disposable worker 執行 CLIP；模型首次需下載，低效能裝置可能較慢或逾時，可取消／手動填寫。瀏覽器以專案長褲照片實測回傳 Bottoms／長褲；3 張本機素材測試中上衣細分類有誤差，因此仍要求確認建議。
- Chrome ZIP 保留資料夾安裝，未上架商店；商家阻擋圖片／網頁讀取時保留連結並提供上傳替代。未宣稱所有購物網站皆可解析。
- 免費 Render 仍可能休眠；本輪壓測不代表長期大量使用可用性或付費正式營運認證。
